Koko Eating Bananas — Binary Search on Answer Space
Intuition
-------------
We need to find the minimum eating speed at which Koko can finish all the bananas within h hours.
The possible speed lies between 1 and the maximum pile size. Since the required hours decrease as the eating speed increases, the valid speeds form a monotonic range. This allows us to use Binary Search on Answer.

Approach
---------
We need to find the minimum eating speed at which Koko can finish all
bananas within h hours.
This is a Binary Search on Answer problem.
The possible eating speed ranges from 1 to the maximum pile size.
For a given speed mid, the hours required to finish a pile is:

ceil(pile / mid)
For positive integers, ceiling division can be calculated as:

(pile + mid - 1) / mid
So we calculate the total hours required for all piles.

If steps <= h, the current speed is valid. Since we need the minimum
valid speed, we store it in ans and search the left half.
If steps > h, the current speed is too slow, so we search the right half.
The reason binary search works is that if a particular speed is sufficient,
then every larger speed will also be sufficient.

Complexity
----------
Time complexity:
Let n be the number of piles and M be the maximum pile size.
Time Complexity: O(n log M)

Space complexity:
---------------
Space Complexity: O(1)
